# Farm Utils

*A calm, quality-of-life RuneLite plugin for tracking farming patch state in Old School RuneScape.*

</div>

---

## Overview

**Farm Utils** is a small, conservative utility focused on making farming state easier to see and reason about — without prescribing routes, optimising outcomes, or removing player judgment.

It exists to reduce cognitive friction in routine play while keeping uncertainty visible and decisions firmly in the player’s hands.

## Status

This project is under active development. Documentation and feature detail will be expanded as the plugin stabilises.
